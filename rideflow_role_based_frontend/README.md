# RideFlow Must UI Frontend

A complete responsive React + Vite frontend for ride booking backend.

## Start

```bash
npm install
npm run dev
```

## Backend URL

Create `.env` file:

```bash
VITE_API_URL=http://localhost:5000/api
```

## Pages

- Home
- Login
- Register
- Dashboard
- Book Ride
- My Bookings
- Driver Panel
- Admin Panel
- Vehicles
- Payments
- Complaints
- Profile
- 404
